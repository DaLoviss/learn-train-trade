# Learn Train Trade

Build a multi page forex trading website named Learn Train Trade, where the aim is to provide an environment for persons to learn trading techniques and principles from my own experience and knowledge and also from free resources currently available on the internet. Take inspiration from https://tanjatrades.com. Do use that websites color scheme and font but use another color scheme preferably purple and yellow. Create a logo with the initials LTT and display it at the top centre.

Pages to create should include;

Home, Resources, Free Education, My Channel

In Resources page, create sub pages ; News, Trading Tools, Prop Firms

In Free Education Page, create sub pages; What is Forex, Learning To Trade, Why Trade
